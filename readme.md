## 🚀 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/rayibharath18-tech/Python-.git
   ```

2. Navigate to the repository:

   ```bash
   cd Python-
   ```

3. Run a Python program:

   ```bash
   python filename.py
   ```

Make sure Python is installed on your computer.
